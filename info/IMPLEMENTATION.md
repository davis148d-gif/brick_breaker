# Implementation Instructions
## Google Scripts
1) Go to [Google Scripts](script.google.com), log in or create an account if necessary
2) Click 'New Project'
3) Paste the code from **code.gs** into the default **code.gs** file automatically created 
4) Create all the HTML files (index, v1,v2,v3,...)
5) Paste the code from the **html** folder into their respective files
6) Click 'Deploy'
7) Select 'New Deployment'
8) Select 'Web App'
9) Click 'Deploy'
10) Visit the URL and play
> For new version updates, you will have to manually add the new files, but for old versions (with the exception of **code.gs**), the JSDelivr CDN link fetched in the ```<script>``` tag will automatically update the game for you. Eventually, you won't even have to add the new files when the Feather version comes out where the **feather.js** file will automatically update to add the new HTML code to run.
> Note: The **code.gs** file probably won't be updated, so it doesn't even matter.

## CodeHS
1) Go to [CodeHS](codehs.com) and sign up or log in
2) Go to the Sandbox
3) Click the arrow next to 'Create a new program'
4) Click create via upload
5) Upload the CodeHS-Upload.zip file in the **game** folder
6) Select HTML as your program type.
7) Click create.
8) Click view program.
9) Done!

## CodeAI
1) Go to [CodeAI](studio.code.org)
2) Go to Projects
3) Create a new Web Lab project
4) Create all the necessary files & paste the appropriate code into them
5) Click **Share** and copy the project URL
6) Enjoy
> For new version updates, you will have to manually add the new files, but for old versions, the JSDelivr CDN link fetched in the ```<script>``` tag will automatically update the game for you. Eventually, you won't even have to add the new files when the Feather version comes out where the **feather.js** file will automatically update to add the new HTML code to run.
