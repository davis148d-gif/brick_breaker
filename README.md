# Brick Breaker 
Aim and shoot a string of balls at bricks to progress and stay alive, purchase upgrades, and set records. Choose different versions from the original Legacy version to the latest v13.0 with upgrades, record tracking, JSON save backups, 15+ types of bricks, and a new 'Hell' gamemode.
## What's in v13
+ Hell mode
+ Updated UI
+ Encrypted JSON save backups

## What's coming in v14.0

## Other Notices
This repository is split into subfolders inside the **game** folder such as: 
+ Google Scripts
+ CodeHS
+ CodeAI

>This is because some people host games on different services and they handle redirects differently, like Google Scripts requiring the redirects to go through the **code.gs** file, and codehs allowing href, so pick a folder that matches the services you use and take the files from there.
