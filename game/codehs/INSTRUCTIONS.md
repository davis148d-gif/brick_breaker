# Instructions for Implementation
1. Create an account to CodeHS 
2. Go to [CodeHS Sandbox](https://codehs.com/sandbox/?id=20)
3. Create a new HTML program
4. Replace the default code in **index.html** with the code in **index.html** in this folder
5. Click the button to create a new file and name it **v1.html**
6. Paste the code in **v1.html** from this folder into that new file
7. Repeat steps 5-6 for the rest of the files in this folder
8. Click **Save**
9. Go to the preview window and click the **Open in new tab** button

# Debugging
+ If CodeHS says 'No site found here', then check all the file names and make sure the game files are named 'v1.html', 'v2.html', ..., otherwise you'll have to change the code in index.html to redirect to different URLs.
