# Instructions for Implementation
1. Go to [Google Scripts](script.google.com)
2. Click 'New Project'
3. Paste the code from the **code.gs** file in this folder into the code.gs file
4. Click the + button (New File) and click 'HTML'
5. Name it 'index' (the .html extension will add itself automatically)
6. Paste the code from the **index.html** file in this folder into the new file
7. Do steps 4-6 for all the other files
8. Click **Deploy** and then click **New Deployment**
9. Set the deployment type to **Web App**
10. Set the settings to whatever you prefer
11. Click **Deploy**
12. Open the Web App URL

# Debugging
+ If it says that the file couldn't be found, check that your files are named 'index.html', 'v1.html', 'v2.html', ... and not something else, because otherwise you'll have to change the code to make it work
