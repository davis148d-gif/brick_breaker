# Instructions for Implementation
1. Log into or create an account on [CodeAI](https://code.org/en-US)
2. Click **Create New Project**, and select **Web Lab (New)**
3. Replace the code in **index.html** with the code in **index.html** in this folder
4. Create a new file called **v1.html** and paste the appropriate code into it
5. Do the same for all the other game files

# Debugging
+ If CodeAI says 'No site found here', then check all the file names and make sure the game files are named 'v1.html', 'v2.html', ..., otherwise you'll have to change the code in index.html to redirect to different URLs.
